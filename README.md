# go-envelopes

Shared Go primitive library for the Envelope UI Protocol — manifest, registry, validator, and plugin extension API.

The companion `ts-envelopes` (TypeScript) package consumes the same YAML manifest for cross-language parity.

> Initial scaffolding commit. The `v0.1.0` extraction from Nanite lands via the open PR.
