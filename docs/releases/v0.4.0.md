# go-envelopes v0.4.0

This release makes the module sufficient for runtime validation and build-time
TypeScript generation, and finishes the cancellation-vocabulary migration that
v0.3.0 deliberately left incomplete.

## Highlights

- `Registry.ExportCatalog`, `codegen.TypeScript`, and
  `cmd/envelopes-export` provide module-resolved manifests, schemas, generated
  types, import metadata, and deterministic source identity without a sibling
  repository checkout.
- `SchemaDocument` / `SchemaMetadata` expose schema annotations, and
  `ValidationError.Details` exposes bounded structured failures while retaining
  existing `errors.Is` / `errors.As` compatibility.
- Core and plugin-defined types use the same registry, schema, catalog,
  validation, and generation contract.
- New Go and wire vocabulary uses US English:
  `ResponseStatusCanceled` (`"canceled"`) and `ErrorCodeUserCanceled`
  (`"user-canceled"`).

## Migration from v0.2.x and v0.3.0

v0.2.x used `"cancelled"` in both response status values and the
`session-task` schema. v0.3.0 changed only the `session-task` schema to
`"canceled"`, leaving the exported Go response and error constants British
spelled.

v0.4.0 makes `"canceled"` / `"user-canceled"` canonical everywhere. To avoid a
consumer flag day, the deprecated `ResponseStatusCancelled`
(`"cancelled"`) and `ErrorCodeUserCancelled` (`"user-cancelled"`) constants
retain their historical values through v0.4.x. `ValidateResponse` and the
`session-task` schema accept legacy `"cancelled"` during the same window, and
generated TypeScript represents that accepted read contract. Use
`ResponseStatus.Canonical` and `CanonicalErrorCode` before re-emitting stored
legacy input.

The British-spelled constants and accepted wire values are scheduled for
removal in v0.5.0. New output must use the US spellings now.

## Generator upgrade

Pin v0.4.0 in the consumer module, then run:

```sh
go run github.com/hollis-labs/go-envelopes/cmd/envelopes-export@v0.4.0 \
  -format typescript -output envelope-types.generated.ts
```

See the [changelog](https://github.com/hollis-labs/go-envelopes/blob/v0.4.0/CHANGELOG.md)
and [generation guide](https://github.com/hollis-labs/go-envelopes/blob/v0.4.0/docs/generation.md)
for the complete API and migration details.
